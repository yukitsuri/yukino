# Module std.os

The `std.os` module provides low-level operating system syscalls, libc bindings, and platform-specific primitives (POSIX/Unix, Linux, Windows, Android) without abstraction overhead.

---

## 1. Import: load std.os

Importing the entire package:

```yukino
// All platform APIs together
load std.os

// Or targeted platform imports
load std.os.unix
load std.os.linux
load std.os.windows
load std.os.android
```

Importing into the current scope provides access to:

- **Constants:**
  - POSIX signals (`SIGHUP`, `SIGINT`, `SIGQUIT`, `SIGILL`, `SIGTRAP`, `SIGABRT`, `SIGKILL`, `SIGUSR1`, `SIGSEGV`, `SIGUSR2`, `SIGPIPE`, `SIGALRM`, `SIGTERM`, `SIGCHLD`, `SIGCONT`, `SIGSTOP`, `SIGTSTP`);
  - Win32 wait constants (`INFINITE`, `WAIT_OBJECT_0`, `WAIT_TIMEOUT`);
  - Android logcat priorities (`ANDROID_LOG_UNKNOWN`, `ANDROID_LOG_DEFAULT`, `ANDROID_LOG_VERBOSE`, `ANDROID_LOG_DEBUG`, `ANDROID_LOG_INFO`, `ANDROID_LOG_WARN`, `ANDROID_LOG_ERROR`, `ANDROID_LOG_FATAL`, `ANDROID_LOG_SILENT`).
- **Error Structures:**
  - `OsError` — operating system low-level error structure.
- **POSIX/Unix Interfaces (`std.os.unix`):**
  - `fork`, `execve`, `waitpid`, `getpid`, `getppid`, `kill`, `chmod`, `chown`, `umask`, `getuid`, `geteuid`, `getgid`, `getegid`, `fcntl`.
- **Linux Interfaces (`std.os.linux`):**
  - `epoll_create1`, `eventfd`, `timerfd_create`, `memfd_create`, `prctl_set_name`, `prctl_get_name`, `gettid`.
- **Windows Interfaces (`std.os.windows`):**
  - `terminate_process`, `get_current_process_id`, `get_process_id`, `close_handle`, `wait_for_single_object`.
- **Android Interfaces (`std.os.android`):**
  - `android_log_print`.

All of these items are also accessible when importing the whole standard library: `load std`.

## 2. Collision-Free libc Symbol Names and Mangling

The Yukino compiler automatically applies safe LLVM IR symbol mangling to all `fun` declarations (pattern `__yukifun_{name}_{args}__{ret}`), preventing any linker symbol collisions with C runtime / libc functions (such as `fork`, `execve`, `getpid`, `kill`, `fcntl`, etc.). Standard canonical function names are used directly in Yukino code:
- `fork`
- `execve`
- `waitpid`
- `getpid` / `getppid`
- `kill`
- `chmod` / `chown`
- `umask`
- `getuid` / `geteuid` / `getgid` / `getegid`
- `fcntl`
- `epoll_create1`
- `eventfd`
- `timerfd_create`
- `memfd_create`
- `gettid`

## 4. Data and Error Structures

### 4.1 OsError

Operating system error structure. In the current implementation no `std.os` function returns it or panics with it: all functions of the module report errors through return values (`-1`, `false`, or `0`).

```yukino
public struct OsError {
    message: string
    code: int32
}
```

- `message` — human-readable description of the operating system error.
- `code` — numeric error code (`errno` on Unix, or a Win32/NTSTATUS error code).

## 5. Function Reference: POSIX and Unix (std.os.unix)

#### 5.1 fork

Invokes system call `fork(2)` to create a new child process by duplicating the calling process.

```yukino
public fun fork() -> int32
```

Returns `0` in the child process, the child PID in the parent process, or `-1` if process creation failed.

This function never panics.

```yukino
load std.os.unix: fork
load std.io: println

set pid = fork()
if pid == 0 {
    println("Child process")
} else if pid > 0 {
    println("Parent process, child PID: ${pid}")
}
```

### 5.2 execve

Replaces the current process image with a new executable at `path` using arguments `args` and environment variables `envs`.

```yukino
public fun execve(path: string, args: string[], envs: string[]) -> int32
```

Upon success, this function does not return to the caller. On failure, returns integer `-1`.

This function never panics.

```yukino
load std.os.unix: execve
load std.io: println

// execve("/bin/ls", ["ls", "-l"], ["PATH=/bin:/usr/bin"])
```

### 5.3 waitpid

Waits for state changes in a child of the calling process `pid` with given `options` (such as `1` for `WNOHANG`).

```yukino
public fun waitpid(pid: int32, options: int32) -> int32
```

Returns the child PID whose state has changed, `0` if `WNOHANG` was specified and no child has exited yet, or `-1` on system call error.

This function never panics.

```yukino
load std.os.unix: waitpid
load std.io: println

set res = waitpid(-1, 1)
println("Wait status: ${res}")
```

### 5.4 getpid / getppid

Returns the process ID (PID) of the calling process and parent process ID (PPID) via `getpid(2)` and `getppid(2)`.

```yukino
public fun getpid() -> int32
public fun getppid() -> int32
```

Returns an `int32` process identifier.

These functions never panic.

```yukino
load std.os.unix: getpid, getppid
load std.io: println

set pid = getpid()
set ppid = getppid()
println("PID: ${pid}, PPID: ${ppid}")
```

### 5.5 kill

Sends signal `sig` to target process `pid` via system call `kill(2)`.

```yukino
public fun kill(pid: int32, sig: int32) -> int32
```

Returns `0` upon success, or `-1` on error.

This function never panics.

```yukino
load std.os.unix: kill, SIGTERM
load std.io: println

set res = kill(1234, SIGTERM)
println("Signal delivery result: ${res}")
```

### 5.6 chmod

Changes access permissions of the file or directory at `path` to the bitmask `mode` (e.g. `0o755`).

```yukino
public fun chmod(path: string, mode: uint32) -> int32
```

Returns `0` upon success, or `-1` on error.

This function never panics.

```yukino
load std.os.unix: chmod
load std.io: println

set res = chmod("script.sh", 493) // 0o755
println("chmod result: ${res}")
```

### 5.7 chown

Changes the owner (`uid`) and group (`gid`) of the specified file or directory at `path`.

```yukino
public fun chown(path: string, uid: uint32, gid: uint32) -> int32
```

Returns `0` upon success, or `-1` on error.

This function never panics.

```yukino
load std.os.unix: chown
load std.io: println

set res = chown("data.bin", 1000, 1000)
println("chown result: ${res}")
```

### 5.8 umask

Sets the process file creation mask to `mask`.

```yukino
public fun umask(mask: uint32) -> uint32
```

Returns the previous file mode creation mask as `uint32`.

This function never panics.

```yukino
load std.os.unix: umask
load std.io: println

set old_mask = umask(18) // 0o022
println("Previous umask: ${old_mask}")
```

### 5.9 getuid / geteuid / getgid / getegid

Returns the real user ID (UID), effective user ID (EUID), real group ID (GID), and effective group ID (EGID) of the calling process.

```yukino
public fun getuid() -> uint32
public fun geteuid() -> uint32
public fun getgid() -> uint32
public fun getegid() -> uint32
```

Returns numeric user or group identifiers as `uint32`.

These functions never panic.

```yukino
load std.os.unix: getuid, geteuid, getgid, getegid
load std.io: println

set uid = getuid()
set gid = getgid()
println("UID: ${uid}, GID: ${gid}")
```

### 5.10 fcntl

Performs low-level file descriptor control operation on `fd` with command `cmd` and argument `arg` (`fcntl(2)`).

```yukino
public fun fcntl(fd: int32, cmd: int32, arg: int32) -> int32
```

Returns non-negative value on success, or `-1` on error.

This function never panics.

```yukino
load std.os.unix: fcntl
load std.io: println

set flags = fcntl(0, 3, 0) // F_GETFL = 3
println("stdin flags: ${flags}")
```

## 6. Function Reference: Linux (std.os.linux)

### 6.1 epoll_create1

Creates an epoll instance with specified `flags` (e.g. `0` or `EPOLL_CLOEXEC` = 0x80000).

```yukino
public fun epoll_create1(flags: int32) -> int32
```

Returns the epoll file descriptor as `int32`, or `-1` on system error.

This function never panics.

```yukino
load std.os.linux: epoll_create1
load std.io: println

set epfd = epoll_create1(0)
println("epoll descriptor: ${epfd}")
```

### 6.2 eventfd

Creates an `eventfd` descriptor for inter-process or inter-thread event notifications with initial counter `initval` and `flags`.

```yukino
public fun eventfd(initval: uint32, flags: int32) -> int32
```

Returns an event file descriptor as `int32`, or `-1` on error.

This function never panics.

```yukino
load std.os.linux: eventfd
load std.io: println

set efd = eventfd(0, 0)
println("eventfd descriptor: ${efd}")
```

### 6.3 timerfd_create

Creates a timer descriptor `timerfd` with the specified clock `clockid` (`0` for `CLOCK_REALTIME`, `1` for `CLOCK_MONOTONIC`) and `flags`.

```yukino
public fun timerfd_create(clockid: int32, flags: int32) -> int32
```

Returns a timer file descriptor as `int32`, or `-1` on error.

This function never panics.

```yukino
load std.os.linux: timerfd_create
load std.io: println

set tfd = timerfd_create(1, 0) // CLOCK_MONOTONIC
println("timerfd descriptor: ${tfd}")
```

### 6.4 memfd_create

Creates an anonymous file descriptor in Linux RAM with name `name` and flags `flags`.

```yukino
public fun memfd_create(name: string, flags: uint32) -> int32
```

Returns a memory file descriptor as `int32`, or `-1` on error.

This function never panics.

```yukino
load std.os.linux: memfd_create
load std.io: println

set mfd = memfd_create("shared_buf", 0)
println("memfd descriptor: ${mfd}")
```

### 6.5 prctl_set_name / prctl_get_name

Sets and retrieves the system thread or process name (up to 16 bytes) via kernel system call `prctl(PR_SET_NAME)`.

```yukino
public fun prctl_set_name(name: string) -> int32
public fun prctl_get_name() -> string
```

`prctl_set_name` returns `0` on success or `-1` on error. `prctl_get_name` returns the current thread name as `string`.

These functions never panic.

```yukino
load std.os.linux: prctl_set_name, prctl_get_name
load std.io: println

prctl_set_name("worker-01")
set name = prctl_get_name()
println("Thread name: " + name)
```

### 6.6 gettid

Returns the Linux kernel thread identification (TID) of the calling thread via `gettid(2)`.

```yukino
public fun gettid() -> int32
```

Returns an integer thread identifier as `int32`.

This function never panics.

```yukino
load std.os.linux: gettid
load std.io: println

set tid = gettid()
println("Kernel TID: ${tid}")
```

## 7. Function Reference: Windows (std.os.windows)

### 7.1 terminate_process

Terminates the specified process `handle` with exit code `exit_code` via Windows API `TerminateProcess`.

```yukino
public fun terminate_process(handle: int64, exit_code: uint32) -> bool
```

Returns `true` if process termination succeeded, otherwise `false`.

This function never panics.

```yukino
load std.os.windows: terminate_process
load std.io: println

// terminate_process(proc_handle, 1)
```

### 7.2 get_current_process_id

Returns the process identifier of the calling process in Windows (`GetCurrentProcessId`).

```yukino
public fun get_current_process_id() -> uint32
```

Returns an unsigned 32-bit process identifier as `uint32`.

This function never panics.

```yukino
load std.os.windows: get_current_process_id
load std.io: println

set pid = get_current_process_id()
println("Win32 PID: ${pid}")
```

### 7.3 get_process_id

Returns the process identifier for the specified open process `handle` (`GetProcessId`).

```yukino
public fun get_process_id(handle: int64) -> uint32
```

Returns process PID as `uint32`, or `0` on invalid handle or error.

This function never panics.

```yukino
load std.os.windows: get_process_id
load std.io: println

// set pid = get_process_id(proc_handle)
```

### 7.4 close_handle

Closes an open Win32 object handle `handle` via `CloseHandle`.

```yukino
public fun close_handle(handle: int64) -> bool
```

Returns `true` if the handle was closed successfully, otherwise `false`.

This function never panics.

```yukino
load std.os.windows: close_handle
load std.io: println

// close_handle(handle)
```

### 7.5 wait_for_single_object

Waits until the specified object `handle` is in the signaled state or time-out interval `timeout_ms` elapses (`WaitForSingleObject`).

```yukino
public fun wait_for_single_object(handle: int64, timeout_ms: uint32) -> uint32
```

Returns wait result status code (`WAIT_OBJECT_0`, `WAIT_TIMEOUT`, or error code).

This function never panics.

```yukino
load std.os.windows: wait_for_single_object, WAIT_OBJECT_0
load std.io: println

// set res = wait_for_single_object(handle, 1000)
// if res == WAIT_OBJECT_0 { println("Object signaled") }
```

## 8. Function Reference: Android (std.os.android)

### 8.1 android_log_print

Sends formatted log message `text` with log tag `tag` and priority `prio` to the Android logcat ring buffer via NDK function `__android_log_print`.

```yukino
public fun android_log_print(prio: int32, tag: string, text: string) -> int32
```

Returns the number of bytes written, or a negative value on error.

This function never panics.

```yukino
load std.os.android: android_log_print, ANDROID_LOG_INFO
load std.io: println

set written = android_log_print(ANDROID_LOG_INFO, "MyApp", "Yukino runtime initialized")
println("Written to logcat: ${written}")
```
