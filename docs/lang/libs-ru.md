# Сторонние библиотеки и экосистема Yukino

Данный документ содержит каталог официальных библиотек и библиотек от сообщества для языка программирования Yukino. А правила добавления ровно такие же, как и в любом культурном интернет-сообществе.

---

## 1. О каталоге пакетов

Yukino — это экспериментальный проект одного разработчика в процессе учебы. По этой причине выделенных серверов, централизованных индексов и облачной инфраструктуры для пакетного менеджера (подобных crates.io или npm) на данный момент не развертывалось (и если вам совсем нечего делать, и вы хотите это исправить, пишите в Discord сервер).

Менеджер пакетов `yukino` изначально спроектирован децентрализованным и поддерживает прямое подключение зависимостей из Git-репозиториев (`git = "..."`), по прямым ссылкам на архивы (`link = "..."`) и по локальным путям (`path = "..."`).

Если вы написали полезную библиотеку для Yukino и хотите поделиться ею с сообществом, вы можете добавить её в этот каталог. Для этого достаточно открыть **Pull Request** с описанием вашей библиотеки, ссылкой на репозиторий и инструкцией по подключению.
