# Модуль std.numf

Модуль `std.numf` (number format) предоставляет набор инструментов для форматирования, преобразования систем счисления и человекочитаемого представления числовых значений в Yukino. Модуль включает функции перевода чисел в произвольные системы счисления (двоичную, шестнадцатеричную, восьмеричную), парсинга строковых представлений с поддержкой префиксов и разделителей, форматирования с разделителями тысяч, выравнивания с дополнением нулями, конвертации размеров данных в единицах IEC/SI и метрических суффиксов.

---

## 1. Подключение: load std.numf

Импорт всего пакета:

```yukino
load std.numf
```

При импорте модуля доступны следующие сущности:

- **Структуры ошибок:** `NumfError`.
- **Функции позиционных систем счисления:** `to_base`, `to_hex`, `to_hex_upper`, `to_bin`, `to_oct`, `parse_base`, `parse_hex`, `parse_bin`, `parse_oct`.
- **Функции форматирования и представления чисел:** `pretty_int`, `pretty`, `pretty_float`, `to_fixed`, `pad_left`, `human_bytes`, `human_metric`, `percent`.

Все перечисленные сущности также автоматически становятся доступны при загрузке всей стандартной библиотеки целиком: `load std`.

## 4. Структуры данных и ошибок (паники)

### 4.1 NumfError

Структура ошибки форматирования чисел, используемая при вызове паники в случае передачи недопустимых аргументов в функции модуля:

```yukino
public struct NumfError {
    message: string
    code: int32
}
```

Поле `message` содержит понятное описание причины ошибки, а `code` — числовой код ошибки:
- `101` — недопустимое основание системы счисления (`radix < 2` или `radix > 36`).
- `102` — отрицательное значение точности (`precision < 0`) или ширины поля (`width < 0`).

## 6. Справочник функций

### 6.1 to_base

Преобразует 64-битное целое число со знаком в строковое представление в позиционной системе счисления с основанием `radix` (от 2 до 36 включительно). Для цифр более 9 используются строчные буквы латинского алфавита от `'a'` до `'z'`. Для отрицательных чисел в начало строки добавляется знак `"-"`.

```yukino
public fun to_base(val: int64, radix: int32) -> string
```

Возвращает строковое значение типа `string`. Возвращаемое значение не nullable.

В случае, если основание `radix` меньше 2 или больше 36, вызывает панику со структурой `NumfError` (код 101).

```yukino
load std.numf: to_base
load std.io: println

set b2 = to_base(10, 2)
set b16 = to_base(255, 16)
set b36 = to_base(35, 36)

println(b2)  // "1010"
println(b16) // "ff"
println(b36) // "z"
```

### 6.2 to_hex

Преобразует 64-битное целое число со знаком в шестнадцатеричную строку в нижнем регистре. Если параметр `prefix` равен `true`, перед цифрами добавляется префикс `"0x"` (для отрицательных чисел — `"-0x"`).

```yukino
public fun to_hex(val: int64, prefix: bool = false) -> string
```

Возвращает строковое значение типа `string`. Возвращаемое значение не nullable.

Функция никогда не вызывает панику.

```yukino
load std.numf: to_hex
load std.io: println

println(to_hex(255, false)) // "ff"
println(to_hex(255, true))  // "0xff"
println(to_hex(-255, true)) // "-0xff"
```

```yukino
load std.numf: to_hex_upper

println(to_hex_upper(255, false)) // "FF"
```


### 6.5 to_oct

Преобразует 64-битное целое число со знаком в восьмеричную строку. Если параметр `prefix` равен `true`, перед цифрами добавляется префикс `"0o"` (для отрицательных чисел — `"-0o"`).

```yukino
public fun to_oct(val: int64, prefix: bool = false) -> string
```

### 6.6 parse_base

Выполняет парсинг строки `s` в позиционной системе счисления с основанием `radix` (от 2 до 36). Поддерживает опциональный знак `'+'` или `'-'`, пропуск символов подчеркивания `'_'` между цифрами, а также стандартные префиксы (`"0x"`/`"0X"` для шестнадцатеричной системы, `"0b"`/`"0B"` для двоичной, `"0o"`/`"0O"` для восьмеричной).

```yukino
public fun parse_base(s: string, radix: int32) -> int64?
```

Возвращает разобранное 64-битное число со знаком типа `int64?` либо `null`, если строка содержит недопустимые символы, пуста или значение превышает допустимый диапазон `int64`.

В случае, если основание `radix` меньше 2 или больше 36, вызывает панику со структурой `NumfError` (код 101).

```yukino
load std.numf: parse_base
load std.io: println

set val = parse_base("1010", 2)
set hex_val = parse_base("0xDEAD_BEEF", 16)

println(val ?? 0)     // 10
println(hex_val ?? 0) // 3735928559
```

### 6.7 parse_hex

Выполняет парсинг шестнадцатеричной строки. Поддерживает строчные и заглавные цифры `'a'`..`'f'`, опциональный префикс `"0x"` или `"0X"`, знак числа и разделители `'_'`.

```yukino
public fun parse_hex(s: string) -> int64?
```

Возвращает разобранное число типа `int64?` либо `null`, если строка не является корректным шестнадцатеричным числом или произошло переполнение.

Функция никогда не вызывает панику.

```yukino
load std.numf: parse_hex
load std.io: println

set val = parse_hex("0xff")
println(val ?? 0) // 255
```

### 6.8 parse_bin

Выполняет парсинг двоичной строки. Поддерживает цифры `'0'` и `'1'`, опциональный префикс `"0b"` или `"0B"`, знак числа и разделители `'_'`.


Возвращает разобранное число типа `int64?` либо `null`, если строка содержит недопустимые цифры или произошло переполнение.

Функция никогда не вызывает панику.

```yukino

load std.io: println

set val = parse_bin("0b1111_0000")
println(val ?? 0) // 240
```

Выполняет парсинг восьмеричной строки. Поддерживает цифры от `'0'` до `'7'`, опциональный префикс `"0o"` или `"0O"`, знак числа и разделители `'_'`.

### 6.10 pretty_int

Форматирует целое число с группировкой разрядов по тысячам, используя указанную строку-разделитель (по умолчанию пробел `" "`).

```yukino
public fun pretty_int(val: int64, separator: string = " ") -> string
```

Возвращает форматированную строку типа `string`. Возвращаемое значение не nullable.

Функция никогда не вызывает панику.

```yukino
load std.numf: pretty_int
load std.io: println

println(pretty_int(1234567, " ")) // "1 234 567"
println(pretty_int(1234567, ",")) // "1,234,567"
println(pretty_int(-1000000))     // "-1 000 000"
```

### 6.12 to_fixed

Форматирует вещественное число с плавающей точкой двойной точности `val` в строковое представление с фиксированным количеством знаков после запятой `precision`. Округление дробной части выполняется по банковскому правилу к ближайшему четному числу (half to even) в соответствии со стандартом IEEE 754.

```yukino
public fun to_fixed(val: float64, precision: int32) -> string
```

Возвращает форматированную строку типа `string`. Возвращаемое значение не nullable. Для специальных значений возвращает `"NaN"`, `"Infinity"` или `"-Infinity"`.

В случае отрицательного значения точности `precision < 0` вызывает панику со структурой `NumfError` (код 102).

```yukino
load std.numf: to_fixed
load std.io: println

println(to_fixed(3.14159, 2)) // "3.14"
println(to_fixed(3.0, 4))     // "3.0000"
println(to_fixed(12.5, 0))    // "12"
println(to_fixed(13.5, 0))    // "14"
```

### 6.13 pretty_float

Форматирует вещественное число с фиксированной точностью дробной части `precision` и разделителем разрядов тысяч в целой части (по умолчанию пробел `" "`).

```yukino
public fun pretty_float(val: float64, precision: int32 = 2, separator: string = " ") -> string
```

Возвращает форматированную строку типа `string`. Возвращаемое значение не nullable.

В случае отрицательного значения точности `precision < 0` вызывает панику со структурой `NumfError` (код 102).


### 6.14 pad_left

Дополняет строковое представление целого числа `val` указанным символом или строкой `pad_char` (по умолчанию `"0"`) слева до достижения общей ширины `width`. Для отрицательных чисел при заполнении нулями знак `"-"` сохраняется в начале строки (например, `"-0042"`).

```yukino
public fun pad_left(val: int64, width: int32, pad_char: string = "0") -> string
```

Возвращает выровненную строку типа `string`. Возвращаемое значение не nullable.

В случае отрицательного значения ширины `width < 0` вызывает панику со структурой `NumfError` (код 102).

```yukino
load std.numf: pad_left
load std.io: println

println(pad_left(42, 5, "0")) // "00042"
println(pad_left(-42, 5, "0")) // "-0042"
println(pad_left(42, 5, " ")) // "   42"
```

### 6.15 human_bytes

Форматирует количество байт `bytes` в человекочитаемую строку с суффиксами единиц измерения. По умолчанию использует двоичные приставки IEC с множителем 1024 (`"B"`, `"KiB"`, `"MiB"`, `"GiB"`, `"TiB"`, `"PiB"`, `"EiB"`). Если параметр `use_si` равен `true`, использует десятичные приставки SI с множителем 1000 (`"B"`, `"KB"`, `"MB"`, `"GB"`, `"TB"`, `"PB"`, `"EB"`).

```yukino
public fun human_bytes(bytes: int64, use_si: bool = false, precision: int32 = 1) -> string
```

Возвращает форматированную строку типа `string`. Возвращаемое значение не nullable.

В случае отрицательного значения точности `precision < 0` вызывает панику со структурой `NumfError` (код 102).

```yukino
load std.numf: human_bytes
load std.io: println

println(human_bytes(500))         // "500 B"
println(human_bytes(1024))        // "1.0 KiB"
println(human_bytes(1536))        // "1.5 KiB"
println(human_bytes(1048576))     // "1.0 MiB"
println(human_bytes(1000, true))  // "1.0 KB"
```

### 6.16 human_metric

Форматирует вещественное число в компактный метрический формат с краткими масштабирующими суффиксами (`"K"`, `"M"`, `"B"`, `"T"`). Для чисел по модулю менее 1000 суффикс не добавляется.

```yukino
public fun human_metric(val: float64, precision: int32 = 1) -> string
```

Возвращает компактную строку типа `string`. Возвращаемое значение не nullable. Для специальных значений возвращает `"NaN"`, `"Infinity"` или `"-Infinity"`.

В случае отрицательного значения точности `precision < 0` вызывает панику со структурой `NumfError` (код 102).

```yukino
load std.numf: human_metric
load std.io: println

println(human_metric(42.0))            // "42"
println(human_metric(1500.0, 1))       // "1.5K"
println(human_metric(2500000.0, 1))    // "2.5M"
println(human_metric(1000000000.0, 1)) // "1.0B"
println(human_metric(-1500.0, 1))      // "-1.5K"
```

### 6.17 percent

Форматирует коэффициент `val` (где `1.0` соответствует 100%) в процентное строковое представление с суффиксом `"%"`.

```yukino
public fun percent(val: float64, precision: int32 = 1) -> string
```

Возвращает процентную строку типа `string`. Возвращаемое значение не nullable. Для специальных значений возвращает `"NaN"`, `"Infinity"` или `"-Infinity"`.

В случае отрицательного значения точности `precision < 0` вызывает панику со структурой `NumfError` (код 102).

```yukino
load std.numf: percent
load std.io: println

println(percent(0.75, 1))   // "75.0%"
println(percent(0.75, 0))   // "75%"
println(percent(0.1234, 2)) // "12.34%"
println(percent(-0.05, 1))  // "-5.0%"
```
