# Developer documentation

This documentation is intended for developers who are already familiar with functional programming, object-oriented programming, typed languages, compilers, and common development tools. It is not a beginner course.

For learning the project from the beginning, read the numbered documents in order, starting with this overview and continuing with `1-build.md`.
